# Sentimental Review

This is an **Angular** project for building a Sentimental Review application.  
It contains components such as navbar, review form, sidebar, and star rating.

---

## 🚀 Project Setup

### ✅ Prerequisites
- [Node.js](https://nodejs.org/) (v16+ recommended)
- [Angular CLI](https://angular.io/cli)

Install Angular CLI globally if you don’t have it:
```bash
npm install -g @angular/cli

```
---

## Install dependencies 
```bash 
npm install
ng build
```
